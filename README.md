# Birthday 2026 — Birthday Film

This is the updated sequel to the old Netflix-style birthday site.

## What was reused
- `images/profile1.jpg`, `profile2.jpg`, `profile3.jpg` — original profile/memory images.
- `images/hero-memory.mp4` — original 2025 hero video.
- `memories-2025.mp4` — original 53-second memory video.
- `narration.mp4` — the supplied 14-second Bridgerton dialogue clip.
- `audio/old-etu.mp3` — preserved from the old site but intentionally NOT used.

## Add the new song
The site is designed around a violin cover of **I Wanna Be Yours**.

Put a legally obtained/licensed MP3 cover here:

`audio/wanna-be-yours-cover.mp3`

The filename must be exact. If it isn't present, the site still works and simply shows a small reminder.

## GitHub Pages
1. Upload the contents of this folder to the repository (not the outer ZIP folder).
2. Make sure `index.html` is in the repository root.
3. Enable GitHub Pages from the repository's Pages settings.
4. Open the generated Pages URL on the phone.

## Experience flow
Opening title → supplied narration clip → cinematic reveal → personal story → old memory film → final birthday message.

The first click starts the experience so mobile browsers are allowed to play audio/video.
